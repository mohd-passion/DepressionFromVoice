# Manuscript Author Review Checklist

Allowed section review statuses:

- `not_reviewed`
- `reviewed_no_change`
- `reviewed_changes_needed`
- `approved`

For each section, reviewers should check factual correctness, methodological completeness, wording clarity, overclaiming, missing references, duplicated material, authorship-sensitive content, confidential information and journal suitability.

## Required Author Review Questions

| Question | Author response |
|---|---|
| Does the manuscript describe the experiments and frozen metrics accurately? |  |
| Are all limitations stated strongly enough for a mental-health AI manuscript? |  |
| Does the manuscript avoid clinical diagnosis, deployment-readiness and fairness claims that were not tested? |  |
| Are any statements sensitive for authorship, institutional policy or dataset-license reasons? |  |
| Is any confidential information present in the manuscript, tables, figure plan or supplement plan? |  |
| Are there additional references the authors require before submission? |  |
| Are any tables or figures inappropriate for the target journal? |  |
