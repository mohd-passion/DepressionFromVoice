# Journal Selection Criteria

These criteria are provisional. Authors may change the weights before selecting the final journal.

| Criterion | Default weight | How to score | Author-adjusted weight |
|---|---:|---|---:|
| Scope fit | 25% | Does the journal explicitly welcome the manuscript's domain, data type and research question? |  |
| Methodological fit | 20% | Does the journal value cross-corpus evaluation, self-supervised speech representations and reproducibility details? |  |
| Audience fit | 15% | Will likely readers understand both speech-processing and mental-health AI aspects? |  |
| Manuscript-length compatibility | 10% | Can the 5,309-word draft fit without damaging methodological transparency? |  |
| Open-access affordability | 10% | Is the APC acceptable or is a no-APC subscription route available? |  |
| Data and code policy compatibility | 10% | Can restricted datasets, excluded raw audio and public code artifacts be explained under the journal policy? |  |
| Figure/supplement compatibility | 5% | Can six tables, seven figure specifications and eleven supplementary candidates be accommodated or trimmed? |  |
| Author preference | 5% | Does the author team prefer a medical, digital-health, speech-processing or biomedical-engineering audience? |  |

## Selection Rule

Do not choose the final journal until the author team supplies APC limits, indexing requirements, open-access requirements and preferred audience. Bibliometric rankings, journal-selectivity claims and publication-speed claims must not be used unless they are rechecked from official or authoritative sources immediately before the decision.
